# 簡單播放使用指南

## 第一次啟動

「簡單播放」本身不播放音訊，而是控制其他 App 建立的 Android MediaSession。第一次開啟時，請點擊「開啟通知存取設定」，並允許「簡單播放媒體控制服務」存取通知。

這項權限用於：

- 找出目前作用中的播放器。
- 顯示歌曲名稱、演唱者與封面。
- 傳送播放、暫停、停止及切歌指令。
- 更新桌面小工具。

如果撤銷通知存取權，主畫面與小工具將無法取得播放器資訊。

## 主畫面

主畫面會顯示：

- 專輯封面或來源 App 圖示。
- 歌曲名稱。
- 演唱者名稱。
- 來源播放器名稱。
- 目前播放器支援的控制按鈕。

若控制按鈕呈停用狀態，代表來源播放器沒有公開該項 MediaSession 操作。

## 切換播放器

當系統同時存在多個 MediaSession 時，主畫面會顯示可用播放器。點擊播放器名稱即可指定控制來源，選擇結果會保存在裝置上。

## App 外觀設定

點擊主畫面右上角齒輪進入設定。

### 顯示模式

- 跟隨系統
- 淺色模式
- 深色模式

### 主題色彩

- 珊瑚橘
- 向日黃
- 湖水綠
- 天空藍
- 葡萄紫
- 莓果粉
- RGB 自訂顏色

設定會立即套用，不需要額外按下儲存。

## 小工具設定

App 提供可調整寬度的控制列小工具，並支援以下外觀設定。

### 按鈕大小

- 小：40dp
- 中：52dp
- 大：64dp

Launcher 實際顯示大小可能受到桌面格線及系統內距影響。

### 顯示模式

- 跟隨系統
- 淺色
- 深色

### 背景樣式

- 主題色背景：背景使用小工具主題色，內容自動使用高對比色。
- 透明背景：文字、來源圖示及控制按鈕使用小工具主題色。

### 主題色彩

可選擇六種預設色彩或使用 RGB 滑桿建立自訂顏色。小工具色彩與 App 主題色可分開設定。

## 新增小工具

1. 長按 Android 桌面空白處。
2. 開啟「小工具」。
3. 找到「簡單播放」。
4. 將「簡單播放控制列」拖曳到桌面。
5. 控制列可水平調整寬度。

控制列會依寬度調整內容：

- `4 x 1`：歌曲資訊、上一首、播放／暫停、下一首。
- `3 x 1`：上一首、播放／暫停、下一首。
- `2 x 1`：播放／暫停、下一首。
- `1 x 1`：播放／暫停。

## 疑難排解

### 畫面顯示「尚未播放」

先在其他音樂或 Podcast App 開始播放，再返回「簡單播放」。

### 小工具沒有更新

1. 確認通知存取權仍然開啟。
2. 確認來源播放器仍有作用中的 MediaSession。
3. 開啟一次「簡單播放」以重新整理狀態。
4. 若 Launcher 快取舊版面，可移除小工具後重新加入。

### 某個按鈕無法使用

來源播放器必須在 MediaSession 中公開對應能力。App 無法強制使用來源播放器未提供的功能。
